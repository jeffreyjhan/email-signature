Click Upload photo on any signature below. The preview updates instantly. When it looks right, click Copy signature and paste into Gmail's signature editor.

How to paste into Gmail: Settings (gear) → See all settings → General → Signature → Create new, name it "Borderless," click into the editor box, Cmd+V. Set it as default for new emails and replies. Save changes at the bottom.

Before you go live

  • Edit the placeholder text in the HTML: Replace Dylan [LastName] and Sidney [LastName], and the +1 (XXX) XXX-XXXX phone numbers. Reload the page, then click Copy.
  • For best deliverability, host the profile photos publicly. Uploaded photos are embedded as base64 data in the copied HTML. Gmail usually handles this fine, but some receiving email clients (older Outlook, especially) may strip data URIs. For maximum compatibility, commit the photos to your Railway images/ folder and I'll rewrite this file to use hosted URLs.
  • Logo renders as inline SVG. Works in Gmail and Apple Mail. If it doesn't render in an edge-case client, export borderless-logo.png from logo-export.html and swap the <svg> block for <img src="..." height="40">.
